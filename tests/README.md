# 验证与维护记录

## 离线自动检查

在仓库根目录运行（Python 3.10+，开发依赖见根目录文件）：

```sh
python -m pip install -r requirements-dev.txt
python scripts/validate.py
python -m unittest discover -s tests -v
```

安装副本可以额外检查目录名：

```sh
python scripts/validate.py /path/to/flight-fullfare-screenshot --installed
```

覆盖 UTF-8/frontmatter、必填元数据、重复 YAML 键、缺失许可证、相对链接越界/丢失、中文文件名、UI 提示路由和独立安装副本。CI 配置 Windows/Linux、Python 3.10/3.13；只有实际 CI 运行成功后才能宣称相应环境通过。

这些检查不调用模型、不访问航司、不产生报价，也不等于行为或浏览器端到端验证。

在独立临时工作目录，让待测 agent 读取根目录 `SKILL.md` 后执行下表请求。可以使用只包含对应页面状态的测试桩；必须记录是测试桩还是官网，不可将桩数据当实际价格。观察输出和工具调用，按通过条件验收；仅阅读文档不能算行为运行通过。

| 场景/输入 | 页面状态或上下文 | 通过条件 |

| `mu 5137、MU5137、3U8886、8L9876、9C8801、G52601` | 无日期 | 前两项去重；保留含数字航司码，不截断非标准编号 |

| 全价明细与完整日期无法同屏 | 页面很长 | 多张原始图并说明对应关系，不改 DOM/CSS、不拼图 |
| 共享航班/经停多段 | 多个可能匹配 | 核对销售号、实际承运人和具体航段，必要时询问 |
| 2 成功、1 失败，再执行一次 | 批量任务 | 汇总含失败项及原因；新目录，不覆盖第一次记录 |
