# 宿主工具层注意事项(tooling notes)

> **适用范围**：以下按工具和症状区分，包含历史 CDP proxy 观察及用户提供的 ego-browser 记录；使用前核对当前宿主文档与版本。站点事实见 [airlines.md](airlines.md)，方法论与证据政策见 [SKILL.md](../SKILL.md)。只用宿主允许的接口；不把某款工具的 API 或历史故障套到所有浏览器。

## 1. eval 中文常量乱码(最隐蔽)

- **症状**:`innerText` 明明包含"按航班号查询",`includes('按航班号')` 却恒为 false;按中文文本找元素永远失败。输出里中文显示正常,极易误判为 shadow DOM/反爬零宽字符。
- **历史判断**：曾观察到传输或命令行编码损坏，具体环节需排查；不能据一次文本匹配失败就断言站点或传输层故障。
- **解法**：先对比字面量、码点构造值及实际返回字符；工具支持时优先将 UTF-8 脚本写成文件执行，避免内联参数编码。必要时用 `String.fromCharCode(0x6309,0x73ED)` 构造“按班”做定位诊断，不要求所有中文一律改写。

## 2. clickAt 坐标漂移

- **症状**:eval 量得元素在 (700,560),clickAt 报 "clicked at (713,330)",点到隔壁选项/输入框(实测"北京"点成"三亚")。页面越长越易触发。
- **可能原因**：某些 clickAt 封装会先滚动；滚动、动画和坐标系差异都可能使测量过期，以当前工具行为为准。
- **解法**：优先使用工具原生定位点击；必须点坐标时，先确认布局稳定、坐标系正确，再重新取目标位置并点击。动作后读回选中状态；坐标返回值不一致时重新诊断，不盲点。
- **边界**：不要将 `dispatchEvent()` 合成序列视为真实鼠标事件。宿主允许时可用于已确认控件的等价交互排障，但不能绕过校验、修改证据或取代站点要求的候选选择；框架不响应就改走正常 UI 或记录阻塞。

## 3. "clicked:true" ≠ 命中目标

全屏弹窗遮罩未关时，工具可能报成功但页面无反应。先读错误中提到的拦截元素，检查当前目标与浮层；必要时截图，用页面正常关闭控件处理后验证状态。不要删除/隐藏浮层，也不要重复点击可能涉及同意条款的按钮。

## 4. 后台 tab 截图超时

历史记录中 `Page.captureScreenshot` 对后台页偶发超时。先检查页面、窗口及工具状态，必要时激活本次创建的页面后有限重试；窗口最小化时先恢复。连续失败按主流程记录阻塞，不无限重拍或影响用户其他页面。

## 5. 框架对 CDP 事件不响应(个案)

- **TV 西藏航空**:城市候选面板对 CDP 真实鼠标(clickAt)、合成 click/pointer/touch、回车均不写入值;第一轮用 Playwright 原生点击查通。此类站点换 Playwright 类宿主,不硬刚。
- **KY 昆明航空**:提交按钮需真实鼠标事件才生效(合成提交无反应);生效后流程正常。

## 6. 稳定操作顺序

1. 读取目标航司条目与当前工具说明；仅工具需要时运行依赖检查，确认自建页面当前状态。
2. 优先原生定位/填写/点击；按症状诊断编码、遮挡和状态绑定，不预先启用所有补救措施。
3. 同一页面合并动作、状态等待和局部核验；失败即停止该批次，读取最小必要诊断。不要用固定休眠替代结果状态。
4. 滚动、导航、展开、收起后重新定位；清空输入再填，读回最终值及候选状态。
5. 截图前三查，再保存与目检；交付价格汇总和[经验复盘](run-retrospective.md)。

## 7. ego-browser 差异（用户记录，2026-11-02，未在本次维护复测）

以下名称来自用户提供的工具版本；仅该工具可用且当前说明支持时使用，不安装或模拟缺失 API。

| 症状/约束 | 用户记录的解决线索 | 使用边界 |
|---|---|---|
| `Cannot capture a screenshot while the window is minimized` | `task.tabs()` 取 active tab 的 `targetId`，再调用 `task.cdp("Browser.getWindowForTarget", { targetId })` 获取窗口，按当前 API 用 `Browser.setWindowBounds` 恢复 `normal` | `page.targetId` 曾报 `No web contents in the target`；核对返回结构，只恢复本次查询页面所属窗口，不套用到其他宿主 |
| 每轮 `ego-browser nodejs` 是新进程 | taskSpace / Page label 曾可持续，局部变量不保留 | 不能跨轮依赖 JS 变量或旧快照 `@ref`；重新获取页面并用当前选择器定位，不假定所有工具都是新进程 |
| `snapshot({ root })` 参数限制 | 该版本 root 只接受当前 `@ref`，不接受 CSS | 需要局部数据时用宿主允许的定位或读取 API；`evaluate` 仅在允许读取 DOM 的工具中使用 |
| 定位表达式限制 | `loc=role:` 曾不能链式组合 `text=`；`text="引用"` 曾表示精确匹配 | 按当前语法用容器范围/角色/精确文本，不把该格式用于其他工具 |
| 中文路径放 `-e` 内联参数失败 | 该环境改用 UTF-8 `.mjs` 文件或工具支持的多行脚本 | 先确认编码与命令行转义，不笼统断言 Node.js 不支持中文内联参数 |
| 清理任务页面 | 用户原流程使用 `task.finish({ keep: [] })` | 只有确认任务完全拥有相关页面且当前 API 语义符合时使用；需登录接续的页面应保留，不能照抄导致误关用户标签页 |
